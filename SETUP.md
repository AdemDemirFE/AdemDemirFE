# AdemDemirFE GitHub Profile — Setup Guide

## How it works

The profile is fully self-hosted: no external statistics providers (vercel.app stat cards, trophy services, or third-party counters). All live numbers come straight from the GitHub API and are written by GitHub Actions.

| Component | Generated by | Written to |
|---|---|---|
| Live metrics table, languages, activity bars in `README.md` | `scripts/update_profile_metrics.py` | `README.md` (between `PROFILE_METRICS` markers) |
| SVG analytics cards (`github-stats`, `top-languages`, `activity`, `achievements`) | `scripts/generate_metrics.py` | `assets/*.svg` |
| Contribution snake | `Platane/snk` action | `output` branch → referenced from `README.md` |

## Workflows

- `.github/workflows/profile-metrics.yml` — refreshes the README metrics table (every 6 h + on push)
- `.github/workflows/metrics.yml` — regenerates the SVG cards in `assets/` (every 6 h + on push)
- `.github/workflows/snake.yml` — publishes the animated snake to the `output` branch (daily)

Both metrics workflows share the same `concurrency` group (`profile-update`) so they can never race each other with conflicting pushes.

## Install

Repository must be:

`AdemDemirFE/AdemDemirFE`

Everything needed is already in the repository root:

- `README.md`
- `scripts/update_profile_metrics.py`
- `scripts/generate_metrics.py`
- `.github/workflows/*.yml`
- `assets/*.svg` (pre-generated placeholders, refreshed by Actions)

## Activate

1. Push the files to the `main` branch.
2. Open **Actions** in GitHub.
3. Run **Update GitHub Profile Metrics** once (workflow_dispatch).
4. Run **Update Profile Metrics** once to generate the SVG cards.
5. Refresh the profile page.

## Important repository setting

If GitHub prevents the workflows from pushing changes, open:

**Settings → Actions → General → Workflow permissions**

and select:

**Read and write permissions**

Then run the workflows again.

## Result

The profile does not need:

- `github-readme-stats.vercel.app`
- `github-readme-activity-graph.vercel.app`
- `github-profile-trophy.vercel.app`
- any third-party visitor counter

All live profile numbers are rendered locally by GitHub Actions.
